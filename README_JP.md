# PFM Compass - 退職計画MVP 🎯

日本市場向けの包括的な退職計画ツール、PFMの2025年製品ロードマップの一部です。このMVPは、構造化されたゲストデータと予約コンバージョンを通じてMILIZEパートナーシップ収益を促進する即座の財務計画インサイトを提供します。

## 📋 概要

**構築内容:** PFM Compass ライフプランニング機能のAI・データサイエンスインフラ  
**理由:** PFMの主要収益化戦略をサポート - MILIZEでの財務プランニングセッション予約1件あたりの収益獲得  
**成功指標:** 検証されたインサイト、デプロイされたインフラ、DynamoDB API経由のクリーンデータ、PFMチームの準備完了

## 🎯 主要機能

### 🔥 **デュアル退職分析**
- **FIREプランニング**: 経済的独立・早期退職計算
- **従来型プランニング**: 日本の年金制度統合による標準退職年齢プランニング

### 🌐 **バイリンガルインターフェース** 
- 日本市場向けの完全な日本語/英語UI
- 日本のユーザーに適した文化的・財務的コンテキスト

### 📊 **高度な分析**
- **138万の事前計算された退職シナリオ**からのリアルタイム検索
- インタラクティブな資産タイムライン可視化
- 日本の財務ベンチマークとの比較分析
- what-ifシナリオモデリング

### 💡 **パーソナライズされたインサイト**
- ユーザープロファイルに基づくAI搭載推奨事項
- ステータスベースのアクションアイテムと次のステップ
- MILIZE専門家予約への統合パスウェイ

### **📋 ステップバイステップインストール順序**

**1. Xcode Command Line Toolsのインストール**（最初に必要）
```bash
xcode-select --install
```
- ポップアップが表示されます → **インストール**をクリック
- これによりmacOSで必要な基本コンパイラとツールが提供されます

**2. Homebrewのインストール**（Mac用パッケージマネージャー）
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
- プロンプトに従い、求められたらMacのパスワードを入力
- **重要:** 最後に表示される`.zprofile`または`.zshrc`に追加する行をコピー＆ペーストしてください
- インストールの確認:
```bash
brew --version
```

**3. Pythonのインストール**（3.9または3.10推奨）
```bash
brew install python@3.10
```
- インストールの確認:
```bash
python3 --version
```

**4. Gitのインストール**（まだインストールされていない場合）
```bash
brew install git
```
- インストールの確認:
```bash
git --version
```

**5. 仮想環境ツールのインストール**
```bash
python3 -m pip install --upgrade pip
python3 -m pip install virtualenv
```

**6. プロジェクトのダウンロードとセットアップ**
```bash
cd ~/Desktop
git clone https://github.com/MT-blamb/pfm_compass_streamlit.git
cd PFM_COMPASS_STREAMLIT
python3 -m venv venv                 # 仮想環境の作成
source venv/bin/activate             # アクティベート
```

**7. Python依存関係のインストール**
```bash
pip install -r requirements.txt
```

**8. アプリケーションの実行**
- シンプルなバイリンガルアプリ:
```bash
streamlit run app_bilingual.py
```
- 高機能版:
```bash
cd bling
streamlit run app.py
```

### **🛠️ Macトラブルシューティング**

**`brew`コマンドが見つからない場合:**
- ターミナルを再起動して再度試してください

**`streamlit`コマンドが見つからない場合:**
- 仮想環境がアクティベートされていることを確認: `source venv/bin/activate`
- 再実行: `pip install -r requirements.txt`

**ポートが既に使用中の場合:**
```bash
streamlit run app_bilingual.py --server.port 8502
```

**権限エラーが発生する場合:**
- 管理者権限を再度申請（5分間のウィンドウが期限切れ）
- 追加サポートについてはITにお問い合わせください

## 📊 データアーキテクチャ

### 事前計算シナリオ
- `/data/pfm_compass_data/`にローカル保存された**138万の退職シナリオ**
- 最適化された検索のためステータス色でパーティション化

### シナリオバケット
システムは以下の組み合わせを分析します：
- **年齢グループ**: 20代、30代（前半/後半）、40代（前半/後半）、50代以上
- **所得レベル**: 年収250万円〜1500万円
- **貯蓄バケット**: 月額貯蓄5万円〜87.5万円
- **支出レベル**: 月額退職支出12.5万円〜50万円
- **人口統計**: 性別、婚姻状況、世帯規模、住宅状況

## 🐛 トラブルシューティング

### 一般的な問題

**「モジュールが見つかりません」エラー:**
```bash
pip install --upgrade -r requirements.txt
```

**ポートが既に使用中:**
```bash
streamlit run app_bilingual.py --server.port 8502
```

**データ読み込み問題:**
- 正しいディレクトリにいることを確認
- `/data/pfm_compass_data/`フォルダが存在することを確認
- parquetファイルが存在することを確認

**Windowsでの権限エラー:**
- コマンドプロンプトを管理者として実行
- またはコマンドプロンプトの代わりにPowerShellを使用

### ヘルプの取得
- エラーメッセージについてはターミナル出力を確認
- Pythonバージョンが3.8以上であることを確認
- リポジトリからすべてのファイルが正しくダウンロードされたことを確認
